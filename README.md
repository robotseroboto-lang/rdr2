# ريد ديد بالعربي — نسخة مستقلة قابلة للتشغيل

المشروع يحافظ على التصميم والمحتوى الأصليين مع التعديلات المطلوبة. لم تُضف شارة Lovable أو أدوات تتبّعها إلى النسخة المستقلة. الحقوق والإشارات إلى روكستار واللعبة باقية.

## ماذا يوجد في الملف؟

- `src/`: كود الموقع القابل للتعديل، بما فيه كل الصفحات السابقة والبحث والفلاتر داخل بطاقات القدرات.
- `dist/`: نسخة الواجهة المبنية مسبقًا.
- `server/`: خادم الأخبار والإدارة والتحديث التلقائي للتحديات.
- `content/`: الأخبار الابتدائية وقاموس ترجمة 416 عنوان تحدٍّ يومي معروف، و241 صياغة خاصة بالمجموعات الأسبوعية.
- `Dockerfile` و`compose.yaml`: تشغيل مستمر مع حفظ البيانات وإعادة تشغيل الخدمة إذا توقفت العملية.
- `ASSET-SOURCES.md`: مصادر الصور والبيانات.

**مهم:** رفع `dist` وحده على استضافة ملفات ثابتة لن يشغّل لوحة الإدارة أو تحديث التحديات. لتشغيل جميع المطلوب، استخدم استضافة تدعم Node.js 22 أو أحدث وتخزينًا دائمًا، أو VPS مع Docker. لا توجد استضافة فعلية مفعّلة ضمن هذا ZIP.

## تشغيل النسخة الجاهزة على الكمبيوتر أو استضافة Node.js

1. ثبّت Node.js 22 أو أحدث، ثم فك الضغط وافتح الطرفية داخل مجلد المشروع.
2. شغّل `npm run setup`. ينشئ `.env` بكلمة مرور عشوائية خاصة ويعرضها لك. لا توجد كلمة مرور مشتركة افتراضية.
3. شغّل `npm start`. لا يحتاج الخادم إلى تثبيت حزم لتشغيل `dist` المبني؛ يستخدم أدوات Node المدمجة فقط.
4. افتح `http://localhost:3000`.
5. لوحة الإدارة: `http://localhost:3000/admin`.

إذا استخدمت عنوانًا غير localhost، عدّل `PUBLIC_ORIGIN` في `.env` ليطابق أصل عنوان الموقع كاملًا (البروتوكول والنطاق والمنفذ)، دون شرطة مائلة في النهاية. بعد إعداد HTTPS ضع `COOKIE_SECURE=true`.

لتعديل الكود وإعادة البناء:

```bash
npm ci
npm run build
npm start
```

للتطوير: شغّل الخادم مع `PORT=3001`، ثم `npm run dev` في طرفية أخرى. اضبط PUBLIC_ORIGIN إلى عنوان Vite المعروض عند تجربة الإدارة من خلاله.

## كيف تعدّل الأخبار بنفسك باستمرار؟

1. افتح `/admin` على نطاق موقعك وسجّل الدخول بكلمة المرور.
2. اضغط «إضافة خبر» أو اختر خبرًا من القائمة.
3. عدّل العنوان والتصنيف والتاريخ والملخص والنص الكامل.
4. ارفع صورة PNG أو JPG أو WebP، بحد أقصى 8 ميجابايت، أو أدخل رابط صورة HTTPS.
5. فعّل «نشر الخبر للزوار» لنشره؛ إلغاء الخيار يحفظه كمسودة خاصة بالإدارة.
6. اضغط «حفظ جميع الأخبار». الزوار يرون التغييرات خلال 30 ثانية أو عند تحديث الصفحة.
7. عندما يحتوي الخبر على نص كامل يظهر زر «اقرأ التفاصيل» تلقائيًا.

الحذف والتعديلات المحلية لا تثبت حتى تضغط الحفظ. إذا عدّل شخص أو تبويب آخر الأخبار، يمنع الخادم الكتابة فوق النسخة الأحدث ويطلب إعادة تحميلها. لا يتم تلقائيًا استبدال أخبارك بأخبار من مصدر خارجي.

## التحديات اليومية والترجمة

المصدر الذي تم اختياره: `https://api.rdo.gg/challenges/index.json`، من RDO.GG / Alloc8or. **مصدر مجتمعي، وليس واجهة رسمية لروكستار**. القسم يوضح ذلك للزائر.

- يعرض 7 تحديات عامة، وثلاثة تحديات لكل دور ضمن مستويات الدور السهلة والمتوسطة والمتقدمة التي يرسلها المصدر.
- يبدأ جلب التحديات اليومية عند 06:10 UTC، أي 09:10 صباحًا بتوقيت السعودية: عشر دقائق بعد إعادة ضبط المصدر. تبقى القائمة السابقة مع تنبيه واضح عند تأخر المصدر.
- يعمل التحديث من الخادم حتى إن لم يكن أي زائر فاتحًا الموقع. لا يستخدم تبويب المتصفح لتشغيل جدولة اليوم الجديد.
- لا يكرر طلب المصدر طول اليوم: يحتفظ بالبيانات حتى نهاية نافذتها. بعد انتهاء اليوم يحاول التحديث، ويعيد المحاولة كل دقيقة إذا انقطع المصدر أو ظل يرسل اليوم السابق.
- الواجهة تستعلم من خادمك كل 15 ثانية، دون إرسال هذه الاستعلامات مباشرةً إلى المصدر الخارجي.
- يحفظ آخر قائمة سليمة على القرص. إذا تأخر المصدر أو انقطع، تظهر القائمة السابقة بعلامة واضحة أنها قديمة؛ لا يعرض بيانات مختلقة أو يقدم القديمة على أنها تحديات اليوم.
- الترجمة ليست ترجمة حرفية يومية من خدمة خارجية: يتم ربط معرّفات التحديات بقاموس عربي خاص باللعبة، يضم 416 صياغة. تظهر المقادير والأهداف كما يرسلها المصدر مع تمييز الأموال والمسافات.
- شرح المطلوب عربي واضح، وأسماء الحيوانات والنباتات والفطر والأطوار مكتوبة بالعربي ثم الإنجليزية بين قوسين لتسهيل مطابقتها داخل اللعبة. أسماء الأسلحة المألوفة مثل ريفولفر وديد آي مكتوبة بحروف عربية. أضيفت توضيحات عربية قصيرة لطريقة إنجاز التحديات.
- يمكن تعديل الصياغات من قسم الترجمات المخصصة داخل `/admin`. مثال:

```json
{
  "MPRC_BOUNTY_USED_LASSO_HORSEBACK": "أمسك المطلوبين باللاسو وأنت على ظهر الحصان"
}
```

إذا أضاف المصدر معرّفًا جديدًا غير موجود في القاموس، يظهر أنه يحتاج مراجعة بدل تخمين ترجمة مضللة. أضف صياغته العربية إلى الترجمات المخصصة. القاموس الحالي يغطي كامل مفردات التحديات المعروفة التي تم الحصول عليها عند إعداد النسخة.

علامات إنجاز التحديات تُحفظ في جهاز الزائر حسب يوم التحديات، ولا تسجّل إنجازًا داخل اللعبة ولا تتصل بحساب Rockstar.

**لا يمكن ضمان عدم الانقطاع إطلاقًا أو الحصول على القائمة في اللحظة نفسها التي تنزل فيها داخل اللعبة.** الاستضافة والشبكة والمصدر الخارجي قد تتعطل أو تتأخر. آلية إعادة المحاولة والتخزين الدائم تقلل أثر ذلك، وتتطلب خادمًا يعمل باستمرار.

## مجموعة مدام نازار الأسبوعية

- أضيفت إلى صفحة `/challenges` تحت التحديات اليومية والأدوار.
- مصدر القائمة الحالية: `https://api.rdo.gg/weekly/index.json`، من RDO.GG / Alloc8or؛ مصدر مجتمعي.
- التجديد المعتاد يوم الثلاثاء 06:00 UTC، أي 09:00 صباحًا بتوقيت السعودية. الخادم يتبع `endTime` الذي يرسله المصدر.
- الكتالوج يشمل 46 مجموعة أسبوعية معروفة و130 عنصرًا مختلفًا ضمنها؛ ترجمات كاملة للأسماء والأوصاف والعناصر، وليس عناصر الأسبوع الحالي فقط.
- تعرض العناصر بأسمائها العربية؛ يضاف الاسم الإنجليزي بين قوسين للعناصر الحيوانية لتسهيل معرفتها.
- اجمع العناصر كلها وبع المجموعة كاملة لمدام نازار أو أرسلها عبر البريد، كما يوضح وصف المجموعة.
- تستخدم الأسبوعية التخزين الدائم وإعادة المحاولة نفسها؛ ملف `data/weekly.json` منفصل عن اليومية، وتعمل جدولة الخادم دون الحاجة إلى زوار.
- يمكن تعديل صياغتها من قاموس `/admin`، مثل `PROVISION_EAGLE_EGG`.
- الكتالوج المرجعي للمجموعات من JeanRopke: `https://github.com/jeanropke/RDR2CollectorsMap/blob/master/data/weekly_sets.json`. لا يستخدم الموقع هذا الملف لتخمين مجموعة الأسبوع الحالي؛ المصدر الحي وحده يحددها.
- هذه هي الأسبوعية التي يوفرها RDO.GG. مكافآت أحداث Newswire الأسبوعية ليست جزءًا من هذا المصدر، ولا تُقدَّم هنا على أنها مترابطة تلقائيًا معه.

## تشغيل مستمر على VPS باستخدام Docker

1. جهّز Docker وDocker Compose على الخادم.
2. أنشئ `.env`، واضبط ADMIN_PASSWORD بكلمة قوية لا تقل عن 12 حرفًا، وPUBLIC_ORIGIN بنطاقك الحقيقي، وCOOKIE_SECURE=true عند استخدام HTTPS.
3. شغّل:

```bash
docker compose up -d --build
docker compose logs -f website
```

4. وجّه نطاقك عبر Nginx أو Caddy إلى `127.0.0.1:3000`، واضبط شهادة HTTPS.
5. حجم Docker المسمى `rdr-data` يحفظ الأخبار والصور المرفوعة وآخر تحديات والترجمات المخصصة. لا تحذفه عند تحديث الموقع.
6. الخدمة يعاد تشغيلها تلقائيًا إذا خرجت العملية أو أعيد تشغيل الخادم. فحص الصحة يظهر تعطل العملية للمراقبة؛ Docker لا يعيد تشغيل عملية لمجرد تحول حالتها إلى unhealthy، لذا أضف مراقبة استضافة وتنبيهًا إذا رغبت.
7. خذ نسخة احتياطية دورية من مجلد البيانات أو الحجم الدائم. لا تخزّنه داخل مساحة مؤقتة تُمسح عند النشر.

شغّل نسخة واحدة من الخادم لكل مجلد بيانات. عند الحاجة للتوسع إلى عدة خوادم يلزم مخزن بيانات مشترك يدعم التزامن.

## إعدادات الاستضافة

| المتغير | معناه |
|---|---|
| ADMIN_PASSWORD | كلمة مرور الإدارة، لا تقل عن 12 حرفًا؛ لا تحفظها في الواجهة |
| PORT | منفذ الخادم، الافتراضي 3000 |
| PUBLIC_ORIGIN | أصل عنوان الموقع مثل https://example.com |
| COOKIE_SECURE | true على HTTPS؛ false للتجربة المحلية فقط |
| DATA_DIR | مكان دائم لحفظ البيانات؛ الافتراضي data داخل المشروع |

## التحقق والحدود

تم بناء الواجهة وفحص TypeScript، واختبار حماية الأخبار والمسودات وحفظها وتعارض التعديلات، واختبار تبدّل يوم التحديات وانقطاع المصدر واسترجاع آخر بيانات صحيحة. أدوات اختبار المتصفح المحلي لم تكن متاحة في بيئة إعداد الملف، لذلك لم تُجرَ مقارنة بصرية آلية أو مراجعة بالمتصفح للنسخة النهائية.

```bash
npm run check
npm test
npm run build
```

لم يتم نشر المشروع أو إعداد نطاق أو تفعيل خدمة استضافة. التحديث المستمر يصبح فعّالًا عند تشغيل الخادم على الاستضافة.

## مدام نازار والخريطة
- `/api/nazar` يحفظ الموقع وتاريخ اللعبة من MadamNazar.io ويعرض صورة المكان المرتبطة بالموقع. يبدأ تحديثه عند 9:10 صباحًا بتوقيت السعودية، ويعيد المحاولة كل دقيقة عند التأخر. لا يخمّن موقعًا جديدًا.
- الخرائط التفاعلية المضمّنة تحتاج الإنترنت، مع رابط فتح مستقل ومصدر واضح.

- أسماء الحيوانات والأسماك داخل الدليل والتحديات بالإنجليزية؛ شرح الفعل والأماكن بالعربية.
- يتم تصحيح اختلاف منطقة/تاريخ نازار في مصدر الصورة عبر مطابقة معلم الموقع مع فترة اليوم الموثقة من RDO.GG، مع الاحتفاظ بتاريخ المصدر الأصلي.

## تعديل آخر الأخبار
افتح `/admin` ثم أضف خبرًا أو اختر خبرًا موجودًا. اكتب العنوان والملخص والتفاصيل، وارفع الصورة، وأضف المصدر وتاريخ انتهاء العرض اختياريًا. فعّل نشر الخبر ثم اضغط «حفظ جميع الأخبار». تظهر التغييرات خلال 30 ثانية. الأخبار التجريبية الأصلية محفوظة كمسودات غير موثقة.

الموقع المنشور على ChatGPT يستخدم حساب المالك لتسجيل الدخول؛ نسخة ZIP المستقلة تستخدم ADMIN_PASSWORD. تم تجهيز الموقع المنشور بربط محمي لتلقي الملخصات العربية من أخبار Rockstar Newswire، لكنه يحتاج اتصال إضافة الموقع والتحقق منها قبل تفعيل مهمة الأخبار الدورية. نسخة ZIP لا تحتوي على خدمة ترجمة تلقائية أو مفتاح API جاهز؛ إدارة الأخبار اليدوية تعمل عبر خادمها.

## الأخبار الحية وحالة الخوادم
يُجلب https://api.rdo.gg/news/index.json تلقائيًا كل 5 دقائق أثناء تصفح الموقع؛ المصدر وسيط مجتمعي لأخبار روكستار وصورها الأصلية. يحفظ الخادم سجل الأخبار، ويعرض تاريخ المصدر لا تاريخ الجلب. خبر الهالوين الحالي له ملخص عربي موثّق؛ الأخبار الجديدة أو المعدلة التي لا توجد لها ترجمة موثقة تظهر بصورتها وتاريخها ورابطها مع تنبيه انتظار الترجمة. لا توجد خدمة ذكاء اصطناعي أو مفتاح ترجمة داخل ZIP؛ الترجمة الشاملة للأخبار القادمة في الموقع المنشور تحتاج تفعيل اتصال إضافة الموقع ثم مهمة الترجمة المحمية.

صفحة /server-status تعرض خوادم ريد ديد فقط من صفحة روكستار الرسمية. تفحص الحالة كل دقيقة: أخضر طبيعي، برتقالي صيانة/خدمة محدودة، أحمر انقطاع، رمادي حالة غير مؤكدة. تظهر أوقات التحقق وتاريخ حالة المصدر، مع الاحتفاظ بالبيانات القديمة والتنبيه عند تعطل المصدر. خادم ZIP يفحص المصدرين في الخلفية باستمرار أثناء تشغيله.

عند تعذر قراءة صفحة الحالة مباشرة، يستخدم الخادم Jina Reader لقراءة الصفحة الرسمية نفسها، مع تجاوز ذاكرة الوسيط والتحقق من رابط المصدر وتاريخه. لا يقبل حالة وسيطة أقدم من 10 دقائق.

GTATracker مصدر أول بديل لحالة المنصات، مع التحقق من تاريخ المصدر واستبعاد GTA. عند تأخر محاولة تحديث، تبقى آخر حالة موثقة لمدة لا تتجاوز3دقائق مع تنبيه؛ بعدها تصبح غير مؤكدة. لا يتغير تاريخ الحالة إلى وقت الجلب.

بطاقة جوائز أكتوبر بجانب خبر الهالوين تعرض الصور المرسلة وشروط جوائز Irontooth وBestShot وRowberrow وAirBanjo وBeatChest. ترتبط بمعرّف خبر الشهر وبصمته الموثقة، وتظهر عليها علامة انتهاء العرض لاحقًا.
